# Résultats du projet — Loi d'Okun

## 1. Résultat du modèle
- Coefficient : -0.7598
- Intercept : 11.0495
- R² : 0.9645

## 2. Interprétation
Le coefficient négatif montre une relation inverse entre la croissance économique et le chômage.

## 3. Conclusion
Les résultats illustrent la loi d'Okun : lorsque la croissance économique augmente, le taux de chômage diminue.

Remarque : les données utilisées sont simulées et non réelles.
